# 漏洞类型验证矩阵（references/vuln-type-matrix.md）

按漏洞类型判断三件事：技术层面什么算"验证成功"、审核层面什么算"及格证据（L2）"、怎么升级。工作流第 2、3 步按需查对应行。

## 目录
注入类 / XSS 类 / 文件类 / 访问控制类 / 配置与协议类 / 逻辑类 / 弱项类（通常不收）

---

## 注入类

| 类型 | 验证成功标准 | 审核及格线（L2 证据） | 常见死法 | 升级路径 |
|---|---|---|---|---|
| SQL 注入 | 布尔差异/时间延迟/报错回显，3 次稳定，手工报文 | 可提取数据证明：current_user/库名/表名/几条敏感字段（脱敏） | 只贴 sqlmap 图无手工报文；WAF 拦截页当成功 | 库名→表名→字段→样本；禁 --dump 全库、禁写操作 |
| XXE | 实体注入读到文件或 OOB 出网 | 读到文件内容回显 | 只证明解析 XML | 文件读→SSRF 化 |
| CRLF | 注入的响应头真实出现 | 能 Set-Cookie/会话固定（低~中，封顶低） | 服务器已过滤只剩疑似 | — |

## XSS 类

| 类型 | 验证成功标准 | 审核及格线 | 常见死法 | 升级路径 |
|---|---|---|---|---|
| 反射 XSS | 最新 Chrome 实际执行（弹窗/console 标记），非仅回显 | 执行截图+他人可触发场景 | 只回显未执行；Self-XSS | 可读 cookie（无 HttpOnly）→会话劫持推演；找落库点转存储 |
| 存储 XSS | 落库后他人浏览触发 | 触发页面+受众+无害标记执行证明 | 触发页无人访问 | 打管理后台→CSRF 组合（推演即可） |

## 文件类

| 类型 | 验证成功标准 | 审核及格线 | 常见死法 | 升级路径 |
|---|---|---|---|---|
| 文件上传 | 上传成功+URL 可访问，报文齐全 | 分档：脚本被解析=高危；同域可渲染执行 JS=中危；纯存储+attachment=低~中危 | 只证明"能传"；危害全写钓鱼推演 | 试解析（双扩展/Content-Type）→试渲染绕过→试桶列举→试预览/WOPI 接口越权→试路径穿越写→检查响应头 Allow 的 PUT |
| 任意文件读/下载 | 读 /etc/passwd 或 win.ini | 读到应用配置（数据库凭据/密钥）=中危起 | 只读系统文件无下文 | 系统文件→应用配置→凭据（不连接，只证明格式）→日志翻 token |
| 目录遍历 | 同上 | 同上 | 同上 | 同上 |

## 访问控制类

| 类型 | 验证成功标准 | 审核及格线 | 常见死法 | 升级路径 |
|---|---|---|---|---|
| 未授权访问接口 | 无凭证请求返回 200 且有数据 | 返回含敏感数据（PII/凭据/业务数据）脱敏样本=中危；凭据类=高危 | 返回空/登录页/公开数据="无敏感信息"；返回的是公开数据=不成立 | 先做"成立性三问"（公开性/设计意图）；逐接口枚举找含 PII/密钥的；配写接口=未授权改数据 |
| 越权 IDOR | 改 ID 返回他人数据 | A/B 两自建账号对照，A 拿到/改掉 B 的数据；改密改绑=高危 | 单账号改 ID 返回自己数据；动了真实用户数据（违规） | 读越权→写越权→改密码/绑定=接管 |
| 敏感信息泄露（.git/.env/actuator/备份） | 端点可访问 | 泄露物含可用秘密（密钥/凭据/连接串，不实际使用） | 泄露的是版本号/公开信息=忽略 | env→密钥→影响推演；heapdump→翻 session（升高危） |
| OAuth/OIDC redirect_uri 绕过 | 恶意 redirect_uri 被接受（302 而非 400），含 .evil.com/@ 两向量 | 缺陷本身成立（RFC 6749 要求精确匹配）=中危；自有账号+自有域名拿到 code=高危 | 把 302 当 code 已窃取的证明（只过了第一关） | 自有域名配前缀子域+自有账号走完登录收 code→exchange 换 token（全程自有资产，合规）；补测 PKCE 是否强制、state 是否强制、response_type=token |
| 弱口令/默认口令 | 登录成功截图 | 后台功能敏感性定级（大量数据/可改业务=中~高） | 登的是演示环境；爆破违规 | 登录后盘点功能截图，不动数据 |

## 配置与协议类

| 类型 | 验证成功标准 | 审核及格线 | 常见死法 | 升级路径 |
|---|---|---|---|---|
| CORS 配置错误 | ACAO 反射任意 Origin+ACAC:true+敏感响应体可读 三条件齐备 | 三条件+敏感数据=中危 | 只反射无凭据/接口零认证（零增量）/接口无敏感数据=忽略 | 先查凭据机制（localStorage JWT 则链死）；Cookie 则查 SameSite |
| SSRF | 目标向受控 dnslog/公网服务发请求 | HTTP 级出网+协议可控=中危；读云元数据 169.254.169.254=高危（不使用凭据） | 只 DNS 出网无回显=低危 | 出网→云元数据→内网端口响应差异（少量） |
| RCE/反序列化 | 命令回显或无害 gadget 出网 | 回显/出网=高危 | 无回显无出网=疑似 | 止于 echo/dnslog 标记；禁提权内网留马 |
| JWT/会话 | none 算法/弱密钥/不失效 | 能伪造他人身份=高危 | 只证明能解码（人人能解） | 伪造普通用户→伪造 admin |
| 子域接管 | dangling CNAME+实际注册接管并托管内容 | 接管成功+托管证明=中危 | 只有 dangling CNAME=忽略 | — |
| 配置暴露（actuator/swagger/debug） | 未授权访问端点 | env/heapdump 含秘密=中~高；只 /health=忽略 | 只证明页面能打开 | env→密钥→推演 |

## 逻辑类

| 类型 | 验证成功标准 | 审核及格线 | 常见死法 | 升级路径 |
|---|---|---|---|---|
| 支付/业务逻辑 | 流程被绕过（改价/验证码复用/重置 token 可预测） | 实际业务影响证据（0 元单创建成功，不支付）=中~高 | 页面显示变了但服务端拦住 | 支付→越权→批量（推演） |
| CSRF | 跨站请求带凭证且改状态（先确认 SameSite 不拦截） | 敏感操作受影响=低~中 | SameSite=Lax 下带不上 cookie=不成立 | 与存储 XSS 组合 |
| 短信/邮件轰炸 | 单号码短时 ≥10 条 | 截图计时+条数=低危（封顶低） | 条数不足 | — |

## 弱项类（多数平台忽略，看到就劝退，别浪费提交额度）

开放重定向（裸）、SPF/DMARC 缺失、自弹 Self-XSS、纯版本号泄露、/health 类无内容端点、公开信息汇总（公开电话/地址/邮箱）、点击劫持（无敏感操作）。

## 组合升级思维（低危变中危的正规手法）

单洞到不了 L2 时找同系统链式组合（仍一洞一报，交叉引用）：
- 上传（纯存储）+ 桶列举 = 批量文件泄露
- 上传 + 同域渲染绕过 = 存储 XSS
- 未授权接口 + 泄露密钥对应服务说明 = 第三方资产风险
- 反射 XSS + CSRF = 强制操作/蠕虫（推演标注）
